# Phase 10 — UI polish

## Goal

Excalidraw-quiet chrome, shortcuts, empty state. This closes V1 of the 2D editor.

## In scope

- Left toolbar: pan, select, wall, room, door, window, stamp
- Shortcuts: `V` select, `W` wall, `H` pan, `Ctrl+S` save, space pan, `Esc` cancel
- Empty state copy when the document has no walls
- Bottom bar: zoom, unit, grid step
- Cursor and hover feedback
- Keyboard-accessible theme toggle and tools

## Out of scope

3D toggle working (control may exist disabled)

## Acceptance

- New user can draw a small apartment with keyboard + mouse without reading a manual
- No leftover debug UI
