# Phase 05 — Select and edit

## Goal

Select, move, delete, and edit wall length.

## In scope

- Select tool (click, maybe simple marquee)
- Move selected walls; snap while moving
- Delete (Delete / Backspace)
- Inspector: length mm/m, thickness
- Keep undo/redo working for these edits

## Out of scope

Rotate furniture, openings.

## Acceptance

- Click a wall → it highlights and the inspector shows length
- Move and undo restore previous endpoints
